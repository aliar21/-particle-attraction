# Проект: Particle Text Attraction

### Описание задания

Создана интерактивная визуальная система частиц, которая формирует заданное слово/текст, считываемое из внешнего файла.
Каждая частица стремится к своей целевой точке (структура изображения), реагирует на движение мыши и подчиняется физическим правилам притяжения/отталкивания.

Использована библиотека pygame и внешний конфигурационный файл config.json.


---

### Дополнительные задачи

1. Реализовано управление силой притяжения через клавиши UP / DOWN.


2. Реализовано очистку сцены клавишей C.


3. Добавлена возможность отображать “следы” частиц (эффект шлейфа).


4. Весь текст формируется из изображения, автоматически сгенерированного из внешнего файла text.txt.




---

## Достигнутая сложность и реализация

### 1. Выполненные основные требования

 Реализована система частиц с притяжением к целевым координатам.

 Частицы реагируют на мышь: отталкиваются в указанном радиусе.

 Изображение текста формируется автоматически на основе содержимого text.txt.

 Настройки вынесены в конфигурационный файл: config.json (цвета, размеры, сила притяжения, путь к тексту, параметры частиц).

 Код структурирован по принципам ООП: выделен класс Particle.

 Частицы появляются случайно и собираются в форму текста.



---

### 2. Дополнительная функциональность

 Динамическое изменение силы притяжения клавишами UP / DOWN.

 Клавиша C полностью очищает текущую систему частиц.

 Реализован визуальный эффект следов частиц (trail mode).

 Поддержка любого текста — достаточно изменить содержимое text.txt.

 Загрузка всех данных из внешнего конфига: окно, цвета, количество частиц, скорость анимации, параметры физики.



---

### 3. Оригинальные расширения

 Добавлен “шум движения” — лёгкое дрожание частиц для более живой анимации.

 Возможность легко менять любой параметр: скорость, цвет, размер частиц, физику.

 Ограничение максимальной скорости для плавности.
